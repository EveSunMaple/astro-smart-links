This page shows how to use [Tailwind CSS](https://tailwindcss.com/) utilities as `astro-smart-links` class names to give every link type a consistent style. Each example can be copied straight into `astro.config.mjs`.

## Basic Styles

Distinguish link types with colors and underlines:

<CodeExample
  title="Basic Tailwind Styles"
  internalLinkHtml='<a href="/en/about" class="text-blue-600 hover:text-blue-800 underline transition-colors">About page</a>'
  externalLinkHtml='<a href="https://github.com" class="text-purple-600 hover:text-purple-800 underline transition-colors" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/en/non-existent" class="text-red-600 hover:text-red-800 line-through transition-colors">Broken link</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'text-blue-600 hover:text-blue-800 underline transition-colors',
  externalLinkClass: 'text-purple-600 hover:text-purple-800 underline transition-colors',
  brokenLinkClass: 'text-red-600 hover:text-red-800 line-through transition-colors',
}),
```
</CodeExample>

## Card Links

Wrap link content in a card, ideal for article lists and navigation:

  title="Card Links"

  brokenLinkClass: 'block p-4 bg-base-100 border border-base-300 rounded-lg shadow-sm opacity-75 cursor-not-allowed',
