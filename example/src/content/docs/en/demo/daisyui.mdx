This page shows how to use [daisyUI](https://daisyui.com/) component classes as `astro-smart-links` class names, so links reuse the component library's styles. Every preview is the real output of that config (examples without an icon disable the default ↗ icon with `content: null`).

## Badge Links

Render links as daisyUI badges:

<CodeExample
  title="Badge Links"
  internalLinkHtml='<a href="/en/about" class="badge badge-primary">About page</a>'
  externalLinkHtml='<a href="https://github.com" class="badge badge-secondary" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/en/non-existent" class="badge badge-error">Broken link</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'badge badge-primary',
  externalLinkClass: 'badge badge-secondary',
  brokenLinkClass: 'badge badge-error',
  content: null,
}),
```
</CodeExample>

## Tooltip Links

Wrap links in daisyUI tooltips with `wrapperTemplate` and apply the link classes with `meta.className`:

<CodeExample
  title="Tooltip Links"
  internalLinkHtml='<div class="tooltip tooltip-primary" data-tip="Navigate to the about page"><a href="/en/about" class="link link-hover link-primary">About page</a></div>'
  externalLinkHtml='<div class="tooltip tooltip-secondary" data-tip="Opens in a new tab"><a href="https://github.com" class="link link-hover link-secondary" target="_blank" rel="noopener noreferrer">GitHub</a></div>'
  brokenLinkHtml='<div class="tooltip tooltip-error" data-tip="This link is broken"><a href="/en/non-existent" class="link link-hover link-error">Broken link</a></div>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'link link-hover link-primary',
  externalLinkClass: 'link link-hover link-secondary',
  brokenLinkClass: 'link link-hover link-error',
  wrapperTemplate: (node, type, meta) => {
    const variants = {
      internal: { className: 'tooltip tooltip-primary', tip: 'Navigate to the about page' },
      external: { className: 'tooltip tooltip-secondary', tip: 'Opens in a new tab' },
      broken: { className: 'tooltip tooltip-error', tip: 'This link is broken' },
    };
    const { className, tip } = variants[type];

    node.properties.className = [...(node.properties.className || []), meta.className];

    return {
      type: 'element',
      tagName: 'div',
      properties: { className: [className], 'data-tip': tip },
      children: [node],
    };
  },
}),
```
</CodeExample>

## Theme-Aware Links

daisyUI colors come from theme variables, so links follow the active theme:

<CodeExample
  title="Theme-Aware Links"
  internalLinkHtml='<a href="/en/about" class="link link-primary">About page</a>'
  externalLinkHtml='<a href="https://github.com" class="link link-accent" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/en/non-existent" class="link link-error">Broken link</a>'
>
```css
/* global.css */
@plugin "daisyui" {
  themes: light --default, dark --prefersdark;
}
```

```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'link link-primary',
  externalLinkClass: 'link link-accent',
  brokenLinkClass: 'link link-error',
  content: null,
}),
```
</CodeExample>

## Combined Components

Combine several component classes, e.g. a button with a badge:

<CodeExample
  title="Combined Components"
  internalLinkHtml='<a href="/en/about" class="btn btn-primary btn-sm gap-2">About page<span class="badge badge-sm">Internal</span></a>'
  externalLinkHtml='<a href="https://github.com" class="btn btn-secondary btn-sm gap-2" target="_blank" rel="noopener noreferrer">GitHub<span class="badge badge-sm">External</span></a>'
  brokenLinkHtml='<a href="/en/non-existent" class="btn btn-error btn-sm gap-2">Broken link<span class="badge badge-sm">Missing</span></a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  internalLinkClass: 'btn btn-primary btn-sm gap-2',
  externalLinkClass: 'btn btn-secondary btn-sm gap-2',
  brokenLinkClass: 'btn btn-error btn-sm gap-2',
  wrapperTemplate: (node, type, meta) => {
    const labels = { internal: 'Internal', external: 'External', broken: 'Missing' };

    node.children.push(h('span', { className: 'badge badge-sm' }, labels[type]));
    node.properties.className = [...(node.properties.className || []), meta.className];

    return node;
  },
}),
```
</CodeExample>
