This page covers the advanced features of `astro-smart-links`: custom link structures, link transforms and a complete configuration.

## Custom Link Structure

Fully control the link HTML with `wrapperTemplate`. The callback receives `(node, type, meta)` and returns the replacement node:

<CodeExample
  title="Custom Link Structure"
  internalLinkHtml='<a href="/en/about" class="internal-link flex items-center gap-1">About page<span class="ml-1">📄</span></a>'
  externalLinkHtml='<a href="https://github.com" class="external-link flex items-center gap-1" target="_blank" rel="noopener noreferrer">GitHub<span class="ml-1">🔗</span></a>'
  brokenLinkHtml='<a href="/en/non-existent" class="broken-link flex items-center gap-1"><span class="mr-1">⚠️</span>Broken link</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  wrapperTemplate: (node, type) => {
    const icons = {
      internal: ['after', '📄'],
      external: ['after', '🔗'],
      broken: ['before', '⚠️'],
    };
    const [position, icon] = icons[type];

    if (position === 'before') {
      node.children.unshift(h('span', { className: 'mr-1' }, icon));
    } else {
      node.children.push(h('span', { className: 'ml-1' }, icon));
    }

    node.properties.className = [
      ...(node.properties.className || []),
      'flex',
      'items-center',
      'gap-1',
    ];

    return node;
  },
}),
```
</CodeExample>

## Adding Badges

Append a label to make the link type obvious:

<CodeExample
  title="Adding Badges"
  internalLinkHtml='<a href="/en/about" class="internal-link flex items-center gap-2">About page<span class="badge badge-primary badge-sm">Internal</span></a>'
  externalLinkHtml='<a href="https://github.com" class="external-link flex items-center gap-2" target="_blank" rel="noopener noreferrer">GitHub<span class="badge badge-secondary badge-sm">External</span></a>'
  brokenLinkHtml='<a href="/en/non-existent" class="broken-link flex items-center gap-2">Broken link<span class="badge badge-error badge-sm">Missing</span></a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  wrapperTemplate: (node, type) => {
    const badges = {
      internal: ['badge badge-primary badge-sm', 'Internal'],
      external: ['badge badge-secondary badge-sm', 'External'],
      broken: ['badge badge-error badge-sm', 'Missing'],
    };
    const [className, label] = badges[type];

    node.children.push(h('span', { className }, label));
    node.properties.className = [
      ...(node.properties.className || []),
      'flex',
      'items-center',
      'gap-2',
    ];

    return node;
  },
}),
```
</CodeExample>

## Link Transforms

`customInternalLinkTransform`, `customExternalLinkTransform` and `customBrokenLinkTransform` modify nodes per link type. Each callback receives `(node, meta)`, where `meta.href` and `meta.pathname` describe the current link:

<CodeExample
  title="Link Transforms"
  internalLinkHtml='<a href="/en/documentation/getting-started" class="internal-link" data-section="docs">Getting started</a>'
  externalLinkHtml='<a href="https://github.com" class="external-link github-link" target="_blank" rel="noopener noreferrer" data-external="true">GitHub</a>'
  brokenLinkHtml='<a href="/en/non-existent" class="broken-link" data-error="true" title="This page does not exist">Broken link</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  customInternalLinkTransform: (node, meta) => {
    if (meta.pathname?.includes('getting-started')) {
      node.properties['data-section'] = 'docs';
    }
  },
  customExternalLinkTransform: (node, meta) => {
    // Custom transforms take over the link entirely, set attributes yourself
    node.properties.target = '_blank';
    node.properties.rel = 'noopener noreferrer';
    node.properties['data-external'] = 'true';

    if (meta.href.includes('github.com')) {
      node.properties.className = [
        ...(node.properties.className || []),
        'github-link',
      ];
    }
  },
  customBrokenLinkTransform: (node) => {
    node.properties['data-error'] = 'true';
    node.properties.title = 'This page does not exist';
  },
}),
```
</CodeExample>

## Ignoring Links

Skip drafts and preview links with `ignore`, which accepts string prefixes and regular expressions:

<CodeExample
  title="Ignoring Links"
  internalLinkHtml='<a href="/en/draft/post" class="internal-link">Draft link (ignored)</a>'
  externalLinkHtml='<a href="https://example.com" class="external-link" target="_blank" rel="noopener noreferrer">Regular external link</a>'
  brokenLinkHtml='<a href="/en/preview/post" class="broken-link">Preview link excluded from checks</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  ignore: ['/draft/', /\/preview\//],
}),
```
</CodeExample>

## Complete Configuration

A complete example combining the most common options:

<CodeExample
  title="Complete Configuration"
  internalLinkHtml='<a href="/en/about" class="internal-link">About page</a>'
  externalLinkHtml='<a href="https://github.com" class="external-link" target="_blank" rel="noopener noreferrer">GitHub<span class="external-icon">↗</span></a>'
  brokenLinkHtml='<a href="/en/non-existent" class="broken-link">Broken link</a>'
>
```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import { smartLinks } from 'astro-smart-links';

export default defineConfig({
  integrations: [
    smartLinks({
      internalLinkClass: 'internal-link',
      externalLinkClass: 'external-link',
      brokenLinkClass: 'broken-link',
      target: '_blank',
      rel: 'noopener noreferrer',
      ignore: ['/draft/'],

      // Broken link handling
      failOnBroken: true,
      reportFile: '.smart-links-report.json',
    }),
  ],
});
```
</CodeExample>
