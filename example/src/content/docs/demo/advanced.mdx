本页面介绍 `astro-smart-links` 的高级用法：自定义链接结构、链接转换与完整配置。

## 自定义链接结构

用 `wrapperTemplate` 完全控制链接的 HTML 结构。回调收到 `(node, type, meta)`，返回替换后的节点：

<CodeExample
  title="自定义链接结构"
  internalLinkHtml='<a href="/about" class="internal-link flex items-center gap-1">关于页面<span class="ml-1">📄</span></a>'
  externalLinkHtml='<a href="https://github.com" class="external-link flex items-center gap-1" target="_blank" rel="noopener noreferrer">GitHub<span class="ml-1">🔗</span></a>'
  brokenLinkHtml='<a href="/non-existent" class="broken-link flex items-center gap-1"><span class="mr-1">⚠️</span>断开链接</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  wrapperTemplate: (node, type) => {
    const icons = {
      internal: ['after', '📄'],
      external: ['after', '🔗'],
      broken: ['before', '⚠️'],
    };
    const [position, icon] = icons[type];

    if (position === 'before') {
      node.children.unshift(h('span', { className: 'mr-1' }, icon));
    } else {
      node.children.push(h('span', { className: 'ml-1' }, icon));
    }

    node.properties.className = [
      ...(node.properties.className || []),
      'flex',
      'items-center',
      'gap-1',
    ];

    return node;
  },
}),
```
</CodeExample>

## 添加徽章

在链接末尾追加标签，直观标注链接类型：

<CodeExample
  title="添加徽章"
  internalLinkHtml='<a href="/about" class="internal-link flex items-center gap-2">关于页面<span class="badge badge-primary badge-sm">内部</span></a>'
  externalLinkHtml='<a href="https://github.com" class="external-link flex items-center gap-2" target="_blank" rel="noopener noreferrer">GitHub<span class="badge badge-secondary badge-sm">外部</span></a>'
  brokenLinkHtml='<a href="/non-existent" class="broken-link flex items-center gap-2">断开链接<span class="badge badge-error badge-sm">失效</span></a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  wrapperTemplate: (node, type) => {
    const badges = {
      internal: ['badge badge-primary badge-sm', '内部'],
      external: ['badge badge-secondary badge-sm', '外部'],
      broken: ['badge badge-error badge-sm', '失效'],
    };
    const [className, label] = badges[type];

    node.children.push(h('span', { className }, label));
    node.properties.className = [
      ...(node.properties.className || []),
      'flex',
      'items-center',
      'gap-2',
    ];

    return node;
  },
}),
```
</CodeExample>

## 链接转换

`customInternalLinkTransform`、`customExternalLinkTransform` 与 `customBrokenLinkTransform` 按类型修改节点，回调收到 `(node, meta)`，`meta.href` 与 `meta.pathname` 描述当前链接：

<CodeExample
  title="链接转换"
  internalLinkHtml='<a href="/documentation/getting-started" class="internal-link" data-section="docs">入门指南</a>'
  externalLinkHtml='<a href="https://github.com" class="external-link github-link" target="_blank" rel="noopener noreferrer" data-external="true">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="broken-link" data-error="true" title="此页面不存在">断开链接</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  customInternalLinkTransform: (node, meta) => {
    if (meta.pathname?.includes('getting-started')) {
      node.properties['data-section'] = 'docs';
    }
  },
  customExternalLinkTransform: (node, meta) => {
    // 自定义转换会完全接管该类链接，需要自行设置属性
    node.properties.target = '_blank';
    node.properties.rel = 'noopener noreferrer';
    node.properties['data-external'] = 'true';

    if (meta.href.includes('github.com')) {
      node.properties.className = [
        ...(node.properties.className || []),
        'github-link',
      ];
    }
  },
  customBrokenLinkTransform: (node) => {
    node.properties['data-error'] = 'true';
    node.properties.title = '此页面不存在';
  },
}),
```
</CodeExample>

## 忽略链接

草稿、预览等链接可以用 `ignore` 跳过处理，支持字符串前缀和正则：

<CodeExample
  title="忽略链接"
  internalLinkHtml='<a href="/draft/post" class="internal-link">草稿链接（已被忽略）</a>'
  externalLinkHtml='<a href="https://example.com" class="external-link" target="_blank" rel="noopener noreferrer">普通外部链接</a>'
  brokenLinkHtml='<a href="/preview/post" class="broken-link">不会参与断链检查的预览链接</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  ignore: ['/draft/', /\/preview\//],
}),
```
</CodeExample>

## 完整配置

组合常用选项的完整示例：

<CodeExample
  title="完整配置示例"
  internalLinkHtml='<a href="/about" class="internal-link">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="external-link" target="_blank" rel="noopener noreferrer">GitHub<span class="external-icon">↗</span></a>'
  brokenLinkHtml='<a href="/non-existent" class="broken-link">断开链接</a>'
>
```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import { smartLinks } from 'astro-smart-links';

export default defineConfig({
  integrations: [
    smartLinks({
      internalLinkClass: 'internal-link',
      externalLinkClass: 'external-link',
      brokenLinkClass: 'broken-link',
      target: '_blank',
      rel: 'noopener noreferrer',
      ignore: ['/draft/'],

      // 断链处理
      failOnBroken: true,
      reportFile: '.smart-links-report.json',
    }),
  ],
});
```
</CodeExample>
