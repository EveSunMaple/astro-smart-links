本页面展示如何用纯 CSS 为链接类名定义丰富的视觉效果。页面上的样式均来自本项目的 `demo-links.css`，可以直接复制使用。

## 基础类名配置

先在集成中指定类名：

<CodeExample
  title="基础类名配置"
  internalLinkHtml='<a href="/about" class="underline-animation">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="border-highlight" target="_blank" rel="noopener noreferrer">GitHub<span class="external-icon">↗</span></a>'
  brokenLinkHtml='<a href="/non-existent" class="warning-link">断开链接</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'underline-animation',
  externalLinkClass: 'border-highlight',
  brokenLinkClass: 'warning-link',
}),
```
</CodeExample>

## 下划线动画

悬停时从左向右展开的下划线：

<CodeExample
  title="下划线动画"
  internalLinkHtml='<a href="/about" class="underline-animation">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="underline-animation" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="underline-animation">断开链接</a>'
>
```css
/* global.css */
.underline-animation {
  position: relative;
  text-decoration: none;
  color: var(--color-primary);
}

.underline-animation::after {
  content: "";
  position: absolute;
  width: 100%;
  height: 2px;
  bottom: -2px;
  left: 0;
  background-color: currentColor;
  transform: scaleX(0);
  transform-origin: left;
  transition: transform 0.3s ease;
}

.underline-animation:hover::after {
  transform: scaleX(1);
}
```
</CodeExample>

## 边框高亮

悬停时高亮虚线下边框：

<CodeExample
  title="边框高亮"
  internalLinkHtml='<a href="/about" class="border-highlight">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="border-highlight" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="border-highlight">断开链接</a>'
>
```css
/* global.css */
.border-highlight {
  text-decoration: none;
  border-bottom: 1px dashed var(--color-accent);
  padding: 0 4px;
  transition: background-color 0.2s, border-color 0.2s;
}

.border-highlight:hover {
  background-color: color-mix(in oklab, var(--color-accent) 10%, transparent);
  border-bottom: 1px solid var(--color-accent);
}
```
</CodeExample>

## 悬停发光

悬停时填充背景并产生光晕：

<CodeExample
  title="悬停发光"
  internalLinkHtml='<a href="/about" class="glow-on-hover">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="glow-on-hover" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="glow-on-hover">断开链接</a>'
>
```css
/* global.css */
.glow-on-hover {
  position: relative;
  text-decoration: none;
  color: var(--color-primary);
  padding: 0 4px;
  transition: color 0.3s;
  z-index: 1;
}

.glow-on-hover::before {
  content: "";
  position: absolute;
  inset: -2px;
  background: transparent;
  border-radius: 4px;
  z-index: -1;
  transition: background 0.3s;
}

.glow-on-hover:hover {
  color: var(--color-primary-content);
}

.glow-on-hover:hover::before {
  background: var(--color-primary);
  box-shadow: 0 0 15px color-mix(in oklab, var(--color-primary) 50%, transparent);
}
```
</CodeExample>

## 断开链接警告

断开链接使用删除线与渐变动画提示用户：

<CodeExample
  title="断开链接警告"
  internalLinkHtml='<a href="/about" class="warning-link">关于页面（样式演示）</a>'
  externalLinkHtml='<a href="https://github.com" class="warning-link" target="_blank" rel="noopener noreferrer">GitHub（样式演示）</a>'
  brokenLinkHtml='<a href="/non-existent" class="warning-link">断开链接</a>'
>
```css
/* global.css */
.warning-link {
  text-decoration: none;
  color: var(--color-error);
  background: linear-gradient(
    to right,
    transparent 50%,
    color-mix(in oklab, var(--color-error) 15%, transparent) 50%
  );
  background-size: 200% 100%;
  background-position: 0 0;
  transition: background-position 0.3s, color 0.3s;
  padding: 0 4px;
  border-radius: 2px;
}

.warning-link:hover {
  background-position: -100% 0;
  text-decoration: line-through;
}
```
</CodeExample>
