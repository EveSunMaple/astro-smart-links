本页面展示如何把 [daisyUI](https://daisyui.com/) 组件类作为 `astro-smart-links` 的类名，让链接直接复用组件库的样式。每个预览区都是该配置的真实输出（不显示图标的示例通过 `content: null` 关闭了默认的 ↗ 图标）。

## 徽章样式链接

把链接渲染成 daisyUI 徽章：

<CodeExample
  title="徽章样式链接"
  internalLinkHtml='<a href="/about" class="badge badge-primary">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="badge badge-secondary" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="badge badge-error">断开链接</a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'badge badge-primary',
  externalLinkClass: 'badge badge-secondary',
  brokenLinkClass: 'badge badge-error',
  content: null,
}),
```
</CodeExample>

## 提示框链接

配合 `wrapperTemplate` 把链接包进 daisyUI 提示框，并用 `meta.className` 应用链接类：

<CodeExample
  title="提示框链接"
  internalLinkHtml='<div class="tooltip tooltip-primary" data-tip="跳转到关于页面"><a href="/about" class="link link-hover link-primary">关于页面</a></div>'
  externalLinkHtml='<div class="tooltip tooltip-secondary" data-tip="在新标签页打开"><a href="https://github.com" class="link link-hover link-secondary" target="_blank" rel="noopener noreferrer">GitHub</a></div>'
  brokenLinkHtml='<div class="tooltip tooltip-error" data-tip="此链接已失效"><a href="/non-existent" class="link link-hover link-error">断开链接</a></div>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'link link-hover link-primary',
  externalLinkClass: 'link link-hover link-secondary',
  brokenLinkClass: 'link link-hover link-error',
  wrapperTemplate: (node, type, meta) => {
    const variants = {
      internal: { className: 'tooltip tooltip-primary', tip: '跳转到关于页面' },
      external: { className: 'tooltip tooltip-secondary', tip: '在新标签页打开' },
      broken: { className: 'tooltip tooltip-error', tip: '此链接已失效' },
    };
    const { className, tip } = variants[type];

    node.properties.className = [...(node.properties.className || []), meta.className];

    return {
      type: 'element',
      tagName: 'div',
      properties: { className: [className], 'data-tip': tip },
      children: [node],
    };
  },
}),
```
</CodeExample>

## 主题自适应链接

daisyUI 的颜色来自主题变量，链接会随主题自动切换：

<CodeExample
  title="主题自适应链接"
  internalLinkHtml='<a href="/about" class="link link-primary">关于页面</a>'
  externalLinkHtml='<a href="https://github.com" class="link link-accent" target="_blank" rel="noopener noreferrer">GitHub</a>'
  brokenLinkHtml='<a href="/non-existent" class="link link-error">断开链接</a>'
>
```css
/* global.css */
@plugin "daisyui" {
  themes: light --default, dark --prefersdark;
}
```

```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';

smartLinks({
  internalLinkClass: 'link link-primary',
  externalLinkClass: 'link link-accent',
  brokenLinkClass: 'link link-error',
  content: null,
}),
```
</CodeExample>

## 组合多个组件

在按钮中追加徽章，组合多种组件类：

<CodeExample
  title="组合多个组件"
  internalLinkHtml='<a href="/about" class="btn btn-primary btn-sm gap-2">关于页面<span class="badge badge-sm">内部</span></a>'
  externalLinkHtml='<a href="https://github.com" class="btn btn-secondary btn-sm gap-2" target="_blank" rel="noopener noreferrer">GitHub<span class="badge badge-sm">外部</span></a>'
  brokenLinkHtml='<a href="/non-existent" class="btn btn-error btn-sm gap-2">断开链接<span class="badge badge-sm">失效</span></a>'
>
```js
// astro.config.mjs
import { smartLinks } from 'astro-smart-links';
import { h } from 'hastscript';

smartLinks({
  internalLinkClass: 'btn btn-primary btn-sm gap-2',
  externalLinkClass: 'btn btn-secondary btn-sm gap-2',
  brokenLinkClass: 'btn btn-error btn-sm gap-2',
  wrapperTemplate: (node, type, meta) => {
    const labels = { internal: '内部', external: '外部', broken: '失效' };

    node.children.push(h('span', { className: 'badge badge-sm' }, labels[type]));
    node.properties.className = [...(node.properties.className || []), meta.className];

    return node;
  },
}),
```
</CodeExample>
